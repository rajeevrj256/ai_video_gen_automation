Media library

Sound effects, background music and 3D models the editor can use. Download them from pixabay.com/sound-effects or pixabay.com/music and add them here. The file name is how Claude knows what it is, so keep names like “sword-slash” or “mysterious-ambient”. Built-in sounds work without adding anything.
Set each file's licence: a file whose licence is unknown is never used in a video (an unlicensed track can bring copyright claims). For CC BY files, write the credit the licence asks for; it is added to the description of every video that uses the file.
